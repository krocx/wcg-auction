# WCG Champions League — Mega Draft Auction

Live auction site for the Weekend Cricket Group. Zero npm dependencies (Node 18+).

| Page | Who | What |
|---|---|---|
| `/` | everyone | Banner, rules, links |
| `/live` | TV, captains, spectators | Live player, bids, purses, SOLD / UNSOLD moments |
| `/squads` | everyone | Squads and prices; copy to WhatsApp, print/PDF, CSV |
| `/sitemap` | everyone | Where-do-I-go guide and list of all pages |
| `/login` | hosts | Email + password, Google, or "create / reset password" by email |
| `/host` | **hosts** (signed in) | Run the auction: draw, bid, sell, undo, backup |
| `/admin` | **owner only** | Invite/remove hosts, practice ↔ live switch, setup check, audit trail |

Spectators and captains never need an account. Only people the owner invites can ever sign in.

## Accounts
- **Owner** = `OWNER_EMAIL` (default `karthik.asvsrk@gmail.com`). First time: `/login` → **Create / reset password** → enter the owner email → open the emailed link.
  If email isn't configured yet, the link is printed in the Render **Logs** tab (look for `/reset?token=`).
- **Hosts**: owner invites them in `/admin`. They get an emailed link (valid 7 days) to create a password, or can use **Continue with Google** with the same address. The admin page also shows the link so you can send it yourself.
- Passwords are hashed (scrypt); sessions are signed HttpOnly cookies; links are single-use; sign-in attempts are rate-limited; removing a host or changing a password signs old sessions out.
- `HOST_PIN` (optional env) is an **emergency host fallback** under `/login → Emergency PIN access`. It never grants `/admin`.

## Practice mode
The site starts in **practice mode**: a yellow banner on every page, results marked as practice. In `/admin`, **Go LIVE** (type `GO LIVE`) ends practice **and clears all auction data**, so practice and the real auction never mix. You can switch back with **START PRACTICE**.

## Coach & site map
A 🎓 **Coach** button (bottom-left on every page) turns guided tips ON/OFF at any time; each page's tour auto-starts on a first visit, and ↻ replays it. The **🗺 Map** button in the top bar and the footer link to the Site map.


## Deploy on Render
Push to GitHub → Render picks up `render.yaml` (Starter plan + 1 GB disk at `/var/data`). Set these env vars in the Render dashboard (Environment tab):

| Variable | Needed for |
|---|---|
| `OWNER_EMAIL` | the owner account (set in render.yaml) |
| `SESSION_SECRET` | auto-generated by render.yaml |
| `RESEND_API_KEY`, `MAIL_FROM` | emailing create-password links |
| `GOOGLE_CLIENT_ID` | Google sign-in |
| `HOST_PIN` | optional emergency PIN |

### Set up email (Resend)
1. Create a free account at resend.com → **API Keys** → create a key → set `RESEND_API_KEY`.
2. Without a verified domain, Resend only lets you send to **your own** signup email (using the default `onboarding@resend.dev` sender). To email other hosts, add and verify a domain in Resend → **Domains**, then set `MAIL_FROM` e.g. `WCG Auction <auction@yourdomain.com>`.
3. Until then, use the **copy link** button in `/admin` and send invites yourself.

### Set up Google sign-in
1. console.cloud.google.com → create/select a project → **APIs & Services → OAuth consent screen** (External, add yourself as a test user).
2. **Credentials → Create credentials → OAuth client ID → Web application**.
3. Under **Authorized JavaScript origins** add `https://wcg-auction.onrender.com` (and `http://localhost:3000` for local testing).
4. Copy the **Client ID** into Render as `GOOGLE_CLIENT_ID`. No client secret is needed.

## Rules implemented (from `WCL_revised_auction.xlsx`)
- 5 teams / captains, **$70M** purse, 32 players in 4 categories with per-player base prices.
- **Squad 7–8 including the captain** → each team buys 6–7 players. At least one player per category.
- IPL-style bidding: +$1M up to $20M, +$2M above; jump bids in $0.5M steps. Category 1 → 4 sets, random inside each.
- **Round 2** for unsold players; assign-at-base for teams that still need players.
- Every bid is checked so no team can be left unable to complete a valid squad; the auction cannot dead-end.

## Host shortcuts
`1`–`5` bid · `Space` going once → twice → SOLD · `N` draw · `U` unsold · `B` undo bid.

## v6 changes (rules, players page, live stream, new look)

**Rules (from `WCL_revised_auction (1).xlsx`)** - 37 players, squads of 8-9 *including* the captain (each team buys 7-8), no mandatory pick per category,
bids in **$0.25M** steps, and the draw is **fully random across all categories**. Round 2 (unsold players) is unchanged.
All of this is editable in the host console under Menu > Team names & settings (bid step, squad sizes, optional "at least 1 per category") until the auction starts.

**Data migration** - on first start after this update, an auction that has *not started yet* (or is in practice mode) is moved to the new roster and rules automatically.
Team names are kept. If a live auction has already started, nothing is touched (the owner can use Players > Load sheet defaults).

**Players page (`/players`)** - everyone can browse; hosts and the owner (signed in) can add / edit / delete players, change category and base price,
change a whole category's base price, upload photos (one by one, or **Bulk photos**: name each file after the player, e.g. `Ravi.jpg`), and the owner can reload the sheet defaults.
Photos are stored on the persistent disk (`DATA_DIR/photos`) and included in Backup/Restore. When a player is sold, the Live page, Players page and Squads show them **in their new team's jersey**.

**YouTube live stream** - host Menu > "YouTube live link" (or Admin > Live stream). Paste a `watch?v=`, `youtube.com/live/..` or `youtu.be/..` link; it appears at the top of `/live` for everyone (muted autoplay, hide / larger buttons). Clear the box to switch it off.

**Look and feel** - the original Disney-night look is the default (Cinzel + Nunito, gold accents). `public/theme.css` only holds player-picture / jersey styles.
The cooler flat alternative ("Stadium Night") is kept in `public/theme-stadium.css` and is not loaded; add `<link rel="stylesheet" href="/theme-stadium.css">` before `</head>` to try it.

**Fun for the audience (Live page)** - the highest bidder is shown in a big team-coloured banner (plus a "LEADING" crown on the team board);
SOLD plays a fanfare, a random-length round of applause and a random "Yayy!" crowd cheer (UNSOLD gets an "Awww"). Sounds are synthesised in the browser - no audio files -
and stay off until the viewer taps "Tap for cheers & sound" (browsers block autoplay). Viewers can tap emoji reactions (clap, party, fire...) that float up on everyone's screen;
five claps in three seconds trigger a burst of applause. The host's bid tiles and jump-bid buttons are gold.
